# Recorded sounds: sources and licences

Every sound in `Resources/Sounds` is a recording released under **CC0 1.0** (public domain,
https://creativecommons.org/publicdomain/zero/1.0/). Credit is not required; it is kept here so
the origin of each file is known. Kenney's sets (`KENNEY_LICENSE.txt`) are CC0 as well.

`Staging/` holds raw takes that `Ashen Woods > Audio > Prepare Recorded Sounds` (SoundPrep.cs)
cuts, trims and normalises into `Resources/Sounds` (footsteps, heartbeat, caught hit, ear
ringing, power restored). Downloaded 2026-11-10.
